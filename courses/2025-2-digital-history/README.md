# 디지털역사학개론

- **개설 학기** 2025학년도 2학기
- **수강 인원** 4명
- **수업 목표** GIS·텍스트 마이닝·통계 분석·네트워크 분석 등 디지털 역사학의 주요 방법론을 익히고, 각자의 주제에 적용하여 개인 프로젝트를 완성한다.

**갤러리: https://littlekg87.github.io/Lecture_Archive/courses/2025-2-digital-history/**

> 2025년에는 학술포스터가 과제 형식으로 정해져 있지 않아 발표자료 형태로 제출되었습니다. 아래 자료는 학생의 발표자료에 실린 이미지를 사용하여 저장소 운영자가 정리한 소개 자료이며, 공개에 동의한 자료만 게시하였습니다. 이미지와 연구 내용의 저작권은 각 제작 학생에게 있습니다.
