## 이 저장소에 대하여

- 이 저장소는 개인이 운영하는 교육 기록이며, 소속 기관의 공식 자료가 아닙니다.
- 게시된 자료는 모두 제작 학생에게 공개 동의를 받은 것입니다. 동의를 받지 못한 자료는 게시하지 않습니다.
- 일부 자료는 학생의 제출물에 실린 이미지를 사용하여 저장소 운영자가 정리한 소개 자료입니다. 해당 자료에는 그 사실을 명시해 두었습니다.

## 저작권

**모든 자료의 저작권은 각 자료를 제작한 학생에게 있습니다.** 저장소 운영자는 저작권자가 아닙니다.

학생들로부터 받은 것은 공개에 대한 동의뿐입니다. 따라서 이 저장소의 자료는 열람과 감상을 위해서만 공개합니다. 복제·배포·변형·2차 사용을 원하시는 경우 반드시 아래 연락처로 문의해 주십시오. 운영자가 학생에게 의사를 확인한 뒤 회신드립니다.

GitHub의 구조상 공개 저장소의 파일은 누구나 내려받거나 복제할 수 있습니다. 기술적으로 막을 수 없으므로, 이용하시는 분들의 협조를 부탁드립니다.
