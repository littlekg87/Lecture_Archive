# Lecture Archive

김근하가 담당한 수업에서 학생들이 만든 학술포스터와 결과물을 모아 두는 곳입니다.
디지털역사학·GIS·AI를 역사학과 사회 문제에 적용한 학부 프로젝트가 중심입니다.

**전시 페이지 → https://littlekg87.github.io/Lecture_Archive**

저장소 화면에서는 파일 목록만 보입니다. 작품은 위 주소에서 보시기 바랍니다.
수업을 고르면 포스터가 격자로 나열되고, 클릭하면 크게 열립니다.

## 저장소 구조

```
index.html                  전체 수업 목록 (전시 페이지 입구)
courses/
  <학기>-<수업명>/
    index.html              해당 수업의 갤러리
    README.md               수업 개요와 작품 목록
    works/                  작품 이미지
```

수업 폴더 이름은 주소가 깨지지 않도록 로마자로 지었고(`2026-1-ai-history`), 작품 파일 이름은
제작 학생의 이름을 로마자로 옮긴 것입니다. 정식 수업명과 학생 이름은 각 페이지에 한글로 표시됩니다.

## 자료 형식

- 작품은 **PNG 또는 JPEG 이미지**로 게시합니다. 대부분 PDF로 제출된 포스터를 이미지로 변환한 것입니다.
- 학생이 제출한 **원본 파일(PDF·PPTX 등)은 게시하지 않습니다.**
- 이미지는 긴 변 2,400픽셀을 기준으로 하며, 화면에서 확대하면 본문 글씨를 읽을 수 있습니다.
  다만 제출본 자체의 해상도가 낮은 경우에는 그렇지 않습니다.

## 이 저장소에 대하여

- 이 저장소는 **개인이 운영하는 교육 기록이며, 소속 기관의 공식 자료가 아닙니다.**
- 게시된 자료는 모두 제작 학생에게 **공개 동의를 받은 것**입니다. 동의를 받지 못한 자료는 게시하지 않습니다.
- 일부 자료는 발표자료 형태로 제출되어, 학생의 제출물에 실린 이미지를 사용하여
  저장소 운영자가 정리한 **소개 자료**입니다. 해당 자료에는 그 사실을 명시해 두었습니다.
  요약문은 운영자가 작성한 것이므로 학생의 논지와 어긋나는 부분이 있을 수 있습니다.
  그런 경우 아래 연락처로 알려 주시면 수정하겠습니다.

## 저작권

**각 작품의 저작권은 그 작품을 제작한 학생에게 있습니다.** 저장소 운영자는 저작권자가 아닙니다.

- 여러 명이 함께 수행한 프로젝트는 **공동저작물**입니다. 이용을 원하시는 경우 참여자 전원의 동의가 필요합니다.
- 포스터 안에는 학생이 직접 제작하지 않은 자료가 포함된 경우가 있습니다.
  배경 지도(구글 지도·OpenStreetMap 등), 통계기관이 발행한 도표, 인용된 지도와 도판,
  포스터 서식, 학교 엠블럼 등이 그렇습니다. **이러한 부분의 권리는 각 원 권리자에게 있으며,
  위의 문장은 학생이 직접 작성·제작한 부분에 관한 것입니다.**

학생들로부터 받은 것은 공개에 대한 동의뿐입니다. 따라서 이 저장소의 자료는 **열람과 감상을 위해서만**
공개합니다. 복제·배포·변형·2차 사용을 원하시는 경우 반드시 아래 연락처로 문의해 주십시오.
운영자가 학생에게 의사를 확인한 뒤 회신드립니다.

GitHub의 구조상 공개 저장소의 파일은 누구나 내려받거나 복제할 수 있습니다.
기술적으로 막을 수 없으므로, 이용하시는 분들의 협조를 부탁드립니다.

## 개인정보

- 작품에는 제작 학생의 **이름**이 표시됩니다. 포스터에 인쇄된 **학번과 소속(학과·학교)** 도
  원본 그대로 보입니다. 포스터 자체를 손대지 않고 게시하기 때문입니다.
- **개인 연락처(이메일·전화번호)는 가려서 게시합니다.** 해당하는 자료가 있는 수업에는 그 사실을 적어 두었습니다.
- 이 저장소는 공개되어 있으므로 검색 엔진에 수집될 수 있습니다.
